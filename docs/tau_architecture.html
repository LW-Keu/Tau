（大脑内核）
→

🔗 一句话总结
👇 tau（你）= 很多张脸（apps/）
同一颗大脑（src/tau_coding + tau_agent + tau_ai）
+ 学到的技能（memory/）
所有前端都在 apps/，大脑在 src/，技能在 memory/，配置在 assets/
