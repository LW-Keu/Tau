🤖 Tau Agent Loop 是什么？

就像机器人"想一想 → 做 → 再想 → 再做"的循环

🔄 核心大循环
转
圈
圈

Tau Agent 不断转圈圈，每转一圈就叫一个 Turn。
最多转 N 圈（max_turns），或者它觉得"搞定！"了就停。

👣 每圈怎么走？
1
🎬 Turn 开始
→
2
🤖 问 AI 大脑
→
3
🔧 做工具
→
4
📦 拿结果
→
5
🔁 下一圈

问 AI → AI 说"用工具XXX" → 做工具 → 拿结果 → 再问 AI → ……

🧰 它会做哪些工具？
💻 code_run
跑代码
📖 file_read
读文件
✏️ file_write
写文件
🔍 web_scan
搜网页
❓ ask_user
问你
💾 checkpoint
存档

工具列表在 assets/tools_schema.json 定义。
每个工具对应一个 do_xxx 方法，用 handler.dispatch() 统一调度。

📢 圈里发生的事（Events）
TurnStarted AssistantTextChunk ToolCallStart ToolOutputChunk TurnEnded

每一步都会发出事件，就像"播报员"告诉大家现在发生什么了。
可以加插件（Hook）来监听这些事件，比如记录到 Langfuse！

🎮 Handler = 工具遥控器
🎮 TauHandler.dispatch("tool_name", args)
↓
找到 do_tool_name 方法
↓
做事 + 返回结果
🔗 一句话总结
🔄 Agent Loop = "问 AI → 做工具 → 再问 → 再做"
循环 N 圈，直到任务完成或达到上限。
Handler 调度工具，Events 记录每一步。
核心文件：tau_agent/agent_loop.py · events.py · handler.py · tools/
