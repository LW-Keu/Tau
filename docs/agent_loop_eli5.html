你只说一次需求,它自己一圈一圈转到做完为止

🤔看结果,再想

🗣️ 光说不练怎么办?

设计了一个「假工具」:不调工具也算一次调用

🤖
我分析了一下,应该这样做……(只输出文字,没调工具)
⚙️
引擎把这次空手回复,当成一个叫 no_tool 的假工具,照样走流程检查——
🔍
真做完了?→ 收工 ✅  回复是空的 / 被截断?→ 让它重来 🔁  贴了段大代码却没执行?→ 追问 🧐
把「不做」也变成一种「做」,所有情况都走同一套检查 — 这就是引擎的自愈能力
